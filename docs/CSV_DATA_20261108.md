## 头像扩展

用户确认由后续 CSV/API 提供头像地址。新增可选列 `AvatarUrl`（HTTPS 绝对地址）；当前六列 CSV 无需改动仍可导入。人员列表、详情、设置预览及来电浮窗均有头像区域，缺失、无效或加载失败时显示姓氏占位。不从旧 SQLite 自动补齐。

头像使用 Coil 异步加载和缓存；有地址时才请求，不影响本地查号。锁屏浮窗不请求或显示人员头像。当前样本已包含地址，实际加载验证见头像数据切换记录；若后续需要单独认证或地址过期刷新，需后端补充协议。

## 导入规则

表头大小写按上表，支持列重排及额外列；必需字段名唯一。支持逗号、引号转义、CRLF / LF 和引号内换行。Id、Name、有效 Phone 必填；岗位或单位为空时明确提示缺失。跳过空行。重复 Id、列数不一致、缺少字段、错误编码、非法引号均拒绝整份导入。限制 20 MiB、100,000 行、六个核心字段每个 2,000 字符。可选头像地址无效或超过 2,000 字符则按无头像处理。

号码去除常见分隔符，对 +86 / 0086 国内号码规范化；按完整号码查号，禁止末几位猜配。未来出现共享号码时保留全部关联人员。

## 加密 API

预计接收加密 CSV；接口、认证、算法、封包和密钥分发尚未约定。下载与认证解密完成后复用同一 CSV 校验和原子替换管线。传输加密与本地存储加密相互独立。当前以全量快照导入；版本、时间、防回滚和增量语义待后端确认。
