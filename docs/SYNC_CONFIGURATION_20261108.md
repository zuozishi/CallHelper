# 人员库同步配置

入口：「数据同步」→「同步配置」齿轮图标，打开二级弹窗。填写 HTTPS URL 和 32 字节 AES-256 密钥的 Base64 字符串，点击勾选图标保存并关闭弹窗，再点击同步图标更新人员库。保存配置不会立即发起网络请求。已有离线人员库保持可用，配置保存后后续启动会自动同步。

扫码界面固定竖屏；扫码图标调用相机（按需申请权限），文件夹图标读取二维码图片。两种导入均先填入表单，核对后点击保存；错误二维码不会修改已保存配置。二维码图标导出当前表单内容，弹窗内下载图标保存 PNG 到用户选择的位置。导出也会验证表单，未保存的有效表单也可导出。

二维码协议：`callhelper://directory-sync?v=1&algorithm=AES-256-GCM&url=<URL编码>&key=<URL编码>`。URL 与 Base64 密钥均按 UTF-8 表单 URL 编码；拒绝未知版本、错误算法、重复或缺失字段。仅支持本应用的配置二维码，不把普通网页二维码作为配置。URL 限制为 1024 字符，不接受 HTTP、内嵌用户名密码或片段。

配置通过独立 Android Keystore 密钥和 AtomicFile 加密保存到 noBackupFilesDir/sync-config.bin。源码和 APK 不再携带旧 URL 或密钥，升级不自动导入旧 APK 密钥。原 secrets 文件不参与构建。密钥表单采用密码显示，不写入界面恢复状态；配置页面禁止截图和最近任务缩略图。导出的二维码图片包含明文密钥，需妥善保管。

本次不改变接口响应协议：Base64(version || nonce || tag || ciphertext)，AES-256-GCM，版本字节作为 AAD；下载、认证或 CSV 校验失败继续保留旧库。
