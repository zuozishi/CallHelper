## 当前行为

按 FullOrgName 的完整路径构建组织树，保留顶级单位之前的祖先层级。当前 4,300 条记录对应 14 个根组织、1,607 个不同完整路径；页面首先显示这 14 个根组织，再逐级展示直接子组织与直属人员，不再把 417 个 TopOrgName 单位平铺为入口。

组织行使用紧凑文件夹布局，约 56dp 最小高度、2dp 间隔。人员行继续保留头像、姓名、岗位、号码；搜索结果额外保留完整组织路径。组织名称可换行，长名称允许增加行高。

面包屑支持横向滚动及回跳；页面内返回和系统返回回到上一层。内存中为各层保存独立滚动位置。搜索覆盖全库，后台防抖执行，按 100 条分批显示；清空搜索恢复原目录。

人员详情新增带无障碍名称“拨号”的图标按钮，使用 ACTION_DIAL 打开系统拨号界面，不申请直接呼叫权限。设备没有拨号应用时显示简短提示。

组织索引随快照在仓库后台构建；浏览时读取当前节点，不在页面重组时扫描全库。单位字段仍用于原有来电信息、统计和检索。路径缺失时回退至 TopOrgName，再缺失则归入“未归属组织”。
