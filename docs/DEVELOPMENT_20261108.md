## 系统来电验证

专用只读模拟器 `emulator-5580`：安装 Debug APK，授予来电识别角色、悬浮窗和可选生命周期权限，通过模拟器 GSM 注入本地 CSV 对应号码。

- 系统电话应用仍为 `com.google.android.dialer`，系统来电通知保留接听/拒接控件。
- 同时存在本应用独立 APPLICATION_OVERLAY 窗口；截图可见对应人员、岗位、单位、组织路径及头像占位。
- 模拟挂断后本应用浮窗移除；未修改系统电话角色。
- 非焦点浮窗未进入默认单窗口 UI dump，人员字段以截图视觉核对，查号数据另由全量设备测试验证。未把单窗口 dump 中缺少字段当作显示失败。

包含真实人员信息的截图、窗口快照与调试日志仅留在 `artifacts/private/device/`，不进入 Git。

## 尚未验收

- 真实 SIM、HyperOS 自启动与后台回收、不同厂商电话页、横竖屏及系统大字体。
- 真实头像服务（当前样本不提供地址），其鉴权、地址过期刷新及离线图片缓存效果。
