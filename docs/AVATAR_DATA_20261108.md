# 0.1.1 头像数据切换与验证

日期：2026-11-08。当前测试源改为用户指定的 `data/export_261108011546.csv`。

## 数据

- UTF-8 CSV，1,258,137 字节，4,300 条人员记录、417 个单位。
- 六个核心字段与原六列文件逐条一致，新增 AvatarUrl。
- 全部记录均包含 HTTPS 头像地址，共 1,811 个不同地址；不推断每个地址都代表不同照片。
- 原始数据、测试资源、头像截图和测试 APK 均被 Git 排除；文档不记录真实人员或头像地址。

## 变更

原解析器已支持 AvatarUrl，此次更新 Debug / androidTest 私有测试资源与准备工具，保持六列和带头像文件兼容。

新增 Debug 数据摘要检查：内置数据变化后更新原内置人员库；0.1.0 无来源标记时核对核心记录，匹配后补入头像。明确标记手动导入的人员库不被自动覆盖。Release 不包含内置测试数据，也不执行此刷新。

版本更新为 0.1.1（versionCode 2），可覆盖安装原测试包。

## 验证

- 18 项单元测试通过。
- Android 17 模拟器 9 项设备测试通过，0 失败；新增真实头像端点解码、Debug 数据升级及手动导入保留验证。
- 全部 4,300 条记录经 Android 解析后保留有效头像地址；实际非公共默认地址的图片下载并解码成功。
- 来电实测截图可见原系统来电接听/拒接控件与独立人员浮窗，头像已经显示为地址对应的图片；模拟挂断后浮窗移除。
- Debug、unsigned Release 构建和 Lint 通过；Release 包无 assets/private。
- Debug APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 原生依赖。

截图等证据仅位于 `artifacts/private/device/`。某些系统来电控件由 SystemUI 通知呈现，因此按电话应用窗口名检测不代表全部显示结果；本次以截图核对系统来电控件与头像显示。
